# Славянский базар в Витебске

Одностраничный адаптивный учебный сайт об истории Международного фестиваля искусств. Переработка предоставленного многостраничного проекта под задание I этапа областного IT-рейтинга 2027 (14–17 лет).

## Запуск

Откройте `index.html` в современном браузере. Сборка, установка библиотек и интернет для основных функций не нужны. Для публикации загрузите содержимое итогового ZIP на любой статический хостинг, например GitHub Pages. Не загружайте рабочую папку `original`.

## Структура итогового проекта

```text
index.html             единственная страница
styles.css             стили, адаптивность, анимации
script.js              интерактивность без зависимостей
img/flower.svg         авторская стилизованная иконка василька
img/main1…main8.webp    оптимизированные фотографии
audio/festival-anthem.mp3
README.md
SOURCES.md             происхождение и ограничения материалов
```

Исходный архив распакован отдельно в `original/slavanskiy-bazar-main` и не изменён. В итоговый ZIP он не включён. Файлы `requirements.txt` и `contact-sheet.jpg` — рабочие материалы, также не входят в поставку.

## Макет и оформление

Референс: [Latest Hotel Booking Website Prototype](https://www.figma.com/design/N8DqLFWTcTnXfCR6jBL7wB/Latest-Hotel-Booking-Website-Prototype--Community-?node-id=0-289).

Использована композиция Home Page из предоставленных скриншотов: компактная шапка, текст слева и фотография справа, три информационных показателя, панель подбора, мозаика из пяти карточек с высокой левой карточкой, горизонтальная фотогалерея, лёгкий подвал и цветная нижняя полоса. Дополнительно размещены необходимые по ТЗ хронология, аудио и форма. Это тематическая адаптация, а не подтверждённая pixel-perfect копия: исходные размеры и типографические спецификации Figma не предоставлены.

Тема сохранена: «Славянский базар в Витебске: история фестиваля». Васильковый синий отсылает к символике фестиваля, золотой акцент — к концертному свету. В отличие от прежней версии, используется светлая двухколоночная композиция вместо полноэкранного баннера. Системный стек Segoe UI / Arial не требует внешних шрифтов; платных шрифтов и CDN нет. Брендовая иконка — самостоятельная стилизация, не официальный логотип.

## Интерактивные элементы

- Мобильное меню: `aria-expanded`, закрытие по ссылке, Escape и клику снаружи.
- Якорная навигация с плавной прокруткой и выделением видимого раздела.
- Фильтр «Музыка и сцена» / «Город и культура» действительно меняет набор карточек и сообщает число результатов.
- Карточки открывают тематический материал в нативном `dialog`; Escape закрывает окно, фокус возвращается к исходной кнопке.
- Хронология использует `details` / `summary` и работает без JS.
- Галерея: нативная горизонтальная прокрутка, кнопки, клавиатура; увеличение фото в диалоге, листание стрелками и свайпом. Автоматического листания нет.
- Аудио запускается только пользователем. Во время воспроизведения вращается декоративная пластинка.
- Проверка имени, email, текста и подтверждения условий; ошибки связаны с полями через `aria-describedby`, установлен `aria-invalid`.
- **Форма демонстрационная: серверная отправка не настроена.** Данные не отправляются и не сохраняются; успешная проверка явно сообщает об этом. Для реальной отправки нужен отдельный согласованный серверный обработчик и политика обработки данных.

## CSS и JavaScript

CSS: custom properties, Grid, Flexbox, fluid-размеры через `clamp`, media queries 2000/1100/760/480/360px, `object-fit`, псевдоэлементы, градиенты, `transform`, `transition`, `@keyframes`, `scroll-snap`, `:focus-visible`, `:hover`, `:active`, `prefers-reduced-motion`. Ширина контента зависит от ширины экрана с плавно меняющимися боковыми полями, а не ограничена прежними 1152 px. Первый экран использует `svh`, диалоги — `dvh`. Поля ввода имеют размер шрифта 16 px для предотвращения нежелательного автозума на iOS.

JS (ES6+): изолирующее замыкание, `const` / `let`, стрелочные функции, шаблонные строки, `querySelector` / `querySelectorAll`, `addEventListener`, `classList`, `dataset`, `setAttribute`, `map`, `every`, `filter`, `IntersectionObserver`, `matchMedia`, `scrollIntoView`, `scrollBy`, `showModal`, `close`, `focus`, `getBoundingClientRect`, touch events. Зависимостей времени выполнения нет.

## Медиа и доступность

Фотографии локальные, преобразованы в WebP качеством 82 с шириной не более 1400 px без увеличения исходника. Водяные знаки сохранены. Для изображений ниже первого экрана задан `loading="lazy"`, у обложки — `fetchpriority="high"`. Аудио имеет `preload="none"`, отсутствует автозапуск.

Использованы `lang="ru"`, семантические HTML5-элементы, заголовки разделов, alt, подписи форм, skip-link, нативный диалог, видимый фокус и `role="status"`. Учитывается уменьшение движения. Аудио снабжено смысловым описанием, **полную проверенную расшифровку необходимо добавить после уточнения текста и прав**. Видео не добавлено: в главном экране макета видеоблока нет. Старый ролик демонстрирует другую версию сайта и не является новой видеодемонстрацией.
