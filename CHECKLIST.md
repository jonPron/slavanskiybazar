# Проверка и видеодемонстрация

## Выполнено

- Сайт просмотрен при ширине 320, 360, 390, 480, 768, 1024, 1440, 1920 и 2560 px: горизонтальная прокрутка отсутствует, ошибок JavaScript нет.
- Проверены мобильное меню, закрытие по ссылке, фильтр «Город и культура», диалог и Escape, четыре ошибки пустой формы и успешная проверка заполненных полей. Просмотрены виды 390 и 1440 px.
- Синтаксис `script.js` проверен через `node --check` без ошибок. HTML прошёл локальный `html-validate` с правилами Prettier; отдельная проверка W3C ещё нужна.
- Скриншоты 1440 и 390 px просмотрены в Microsoft Edge.
- Ошибок в консоли Chromium нет.
- Проверено переполнение документом во фреймах 360, 390, 768 и 1280 CSS px: горизонтальной прокрутки нет.
- Галерея не запускает автолистание: положение меняет пользователь.
- Переход к следующему снимку в увеличенной галерее меняет счётчик на `2 / 5`.
- Формат MP3 распознаётся браузером как поддерживаемый.
