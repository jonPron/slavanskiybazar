# Проверка и видеодемонстрация

## Уже проверено

- После второй переработки дизайна проверены ширины 320, 360, 390, 480, 768, 1024, 1440, 1920 и 2560 px в headless Microsoft Edge: переполнения документа нет, JavaScript-ошибок нет.
- Повторно проверены кликами мобильное меню и закрытие по ссылке, фильтр (2 городские карточки), открытие диалога и Escape, 4 ошибки пустой формы и успешная проверка корректных полей. Просмотрены новые скриншоты 390 и 1440 px, снят общий вид страницы.
- Синтаксис `script.js`: `node --check`, без ошибок. HTML прошёл локальный `html-validate` с рекомендованными правилами и настройками стиля Prettier; это не заменяет отдельную проверку W3C.
- Просмотрены скриншоты новой версии в headless Microsoft Edge: desktop 1440 px и mobile 390 px.
- В консоли встроенного Chromium ошибок не зафиксировано.
- В Chromium программно проверена компоновка во фреймах шириной 360, 390, 768 и 1280 CSS px: горизонтального переполнения страницы нет.
- На каждой ширине фильтр «Город и культура» оставляет две карточки.
- Карточки открывают нативный диалог.
- Пустая форма отмечает четыре обязательных поля/подтверждения; валидные данные проходят проверку без отправки.
- В увеличенной галерее переход к следующему снимку меняет счётчик на `2 / 5`.
- Формат MP3 распознаётся браузером как поддерживаемый. Фактическое прослушивание человеком не заменяется этой проверкой.

## Обязательно проверить перед сдачей

- [ ] Просмотреть сайт целиком на телефоне, планшете и ПК; сверить с оригинальным фреймом Figma, если доступен.
- [ ] Повторить сценарии в Chrome, Firefox и Яндекс.Браузере. Автотест Chromium не означает проверку всех браузеров.
- [ ] Клавиатура: Tab, Shift+Tab, Enter, Escape; возврат фокуса из диалога.
- [ ] Прослушать всю аудиозапись, подтвердить название и добавить проверенную расшифровку.
- [ ] Установить права/авторов для всех медиа (см. SOURCES.md).
- [ ] Проверить `index.html` загрузкой файла на https://validator.w3.org/ и CSS на https://jigsaw.w3.org/css-validator/.
- [ ] Проверить контрастность и доступность скринридером. Наличие ARIA не подтверждает полное соответствие WCAG.
- [ ] Если нужна настоящая отправка: подключить согласованный backend и изменить тексты формы, не показывать ложный успех.
- [ ] Записать новую видеодемонстрацию. Старое видео из исходного архива не относится к этой версии.
- [ ] Убедиться, что использование помощи ИИ допускается организаторами.
